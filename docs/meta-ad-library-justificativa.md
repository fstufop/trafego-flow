# Justificativa — Acesso à Meta Ad Library API

## Texto para o campo "How will you use the Ad Library API?"

Trafego Flow is an internal tool built for personal use to support paid media management for clients running campaigns on Meta platforms (Facebook and Instagram).

The Ad Library API will be used exclusively to:

1. **Competitive research**: Identify active advertisers in specific niches and regions (primarily Brazil) to support client prospecting and campaign strategy.
2. **Market analysis**: Analyze ad creative trends, audience targeting patterns, and advertiser activity within relevant industry segments.
3. **Internal reporting**: Store and cross-reference historical Ad Library data to track competitor activity over time and generate insights for campaign optimization.

All data retrieved from the Ad Library API is publicly available information. It is accessed and stored solely for internal analytical purposes by a single operator (the developer/owner of this application). No data is shared with third parties, resold, or used for any purpose other than internal business analysis.

The application is not a public-facing product. Access is restricted to the developer and is protected by API key authentication.
