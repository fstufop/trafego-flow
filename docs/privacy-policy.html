Política de Privacidade

Última atualização: junho de 2025

Esta política de privacidade descreve como o Trafego Flow coleta, usa e protege as informações no contexto de sua operação interna. O Trafego Flow é uma ferramenta de uso interno desenvolvida para apoiar a gestão de campanhas pagas em plataformas Meta (Facebook e Instagram).

1. Quem somos

O Trafego Flow é operado por Filipe Teodoro como uma ferramenta interna de uso pessoal. Não é um produto público ou comercial. O acesso é restrito ao operador e protegido por autenticação via chave de API.

2. Dados coletados

A aplicação interage com as seguintes fontes de dados:

  • Meta Ad Library API: dados públicos sobre anúncios ativos em plataformas Meta, incluindo nome da página anunciante, estimativas de gasto, impressões, plataformas de veiculação e dados demográficos agregados. Todos esses dados são de acesso público conforme disponibilizados pela própria Meta.
  • Meta Ads API: relatórios e métricas de campanhas de contas de anúncios expressamente autorizadas pelo titular.
  • WhatsApp e Instagram (webhooks): mensagens recebidas em contas de negócios configuradas pelos clientes do operador, exclusivamente para fins de automação de atendimento.

3. Como usamos os dados

  • Análise competitiva e pesquisa de mercado para otimização de campanhas.
  • Geração de relatórios internos de performance.
  • Automação de respostas em canais de mensagem autorizados.

Nenhum dado é compartilhado com terceiros, revendido ou utilizado para fins diferentes dos descritos acima.

4. Armazenamento e segurança

Os dados são armazenados em banco de dados PostgreSQL com acesso restrito. Credenciais de API são criptografadas em repouso usando AES-256. Nenhum dado sensível é registrado em logs de aplicação.

5. Retenção de dados

Dados da Ad Library são retidos pelo tempo necessário para análise histórica e podem ser excluídos a qualquer momento pelo operador. Dados de mensagens (WhatsApp/Instagram) são retidos conforme configuração por conta de cliente e excluídos mediante solicitação.

6. Direitos dos titulares

Como a plataforma é de uso interno e não coleta dados de usuários finais de forma direta, questões relacionadas a dados de terceiros processados via webhooks são de responsabilidade do cliente que configurou a integração. Para solicitações, entre em contato pelo e-mail abaixo.

7. Uso de dados da Meta

O uso de dados obtidos via APIs da Meta segue os Termos de Serviço da Plataforma Meta e a Política de Dados do Facebook. Dados da Ad Library são exclusivamente públicos e utilizados para fins analíticos internos.
